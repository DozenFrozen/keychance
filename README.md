# KeyChance — шанс тайма в Мифик+

Аддон в реальном времени считает вероятность пройти ключ в тайм на основе статистики WarcraftLogs
и вашей собственной истории забегов.

## Как это устроено

Аддоны WoW не имеют доступа к интернету, поэтому данные загружаются отдельно:

```
WarcraftLogs API ──► tools/wcl_fetch.py ──► KeyChance/Data.lua ──► аддон в игре
```

**Скрипт** для каждого данжа и уровня ключа скачивает тайм-забеги из рейтинга WCL и сохраняет:
время прохождения, на какой минуте убит каждый босс, состав (спеки) и урон группы в секунду.
Плюс мета: частота каждого спека в тайм-забегах и его средний DPS на этом уровне.

**Аддон** во время ключа следит за таймером, убитыми боссами, % мобов, составом группы (через осмотр)
и уроном группы, и считает:

- **Шанс тайма** — вероятность уложиться в лимит;
- **Прогноз финиша** и запас/опоздание;
- **Боссы**: на какой минуте их в среднем убивают в тайм-забегах и ваше отставание/опережение;
- **Мету состава**: оценка 0–100% и тир каждого спека (S/A/B/C) по популярности в тайм-забегах;
- **Средний финиш** всех тайм-забегов и забегов с похожим составом (3+ таких же спека);
- **Урон группы** в сравнении со средним уроном групп на этом уровне.

Вне ключа окно показывает предварительную оценку для вашего ключа с текущей группой.

### Модель

Темп группы — это отношение `r = наше время / время эталонного забега`. Для каждого эталонного забега
(того же данжа, уровни ±2, вес выше у похожих составов и у ваших собственных забегов):

1. **Априорный темп** до старта: поправка «логи быстрее обычных групп» (`bias`) + разница уровней ключа
   (~4.5% за уровень) + разница в мете состава + разница в уроне группы (когда урон известен).
2. **Наблюдаемый темп**: после каждого убитого босса сравнивается ваше время с временем эталона.
   Чем дальше вы в данже, тем сильнее наблюдаемый темп вытесняет априорный и тем меньше неопределённость.
3. По оставшемуся времени эталона и вашему темпу считается вероятность успеть (лог-нормальная модель),
   затем результаты усредняются по всем эталонам с весами.

После последнего босса оставшееся время оценивается по недобитым % мобов.

## Установка

1. Скопируйте папку `KeyChance` в `World of Warcraft\_retail_\Interface\AddOns\`.
2. Создайте API-клиент на https://www.warcraftlogs.com/api/clients/ (redirect URL — любой, например
   `http://localhost`). Нужны **Client ID** и **Client Secret**.
3. Загрузите данные (Python 3.9+, без дополнительных библиотек):

   ```powershell
   $env:WCL_CLIENT_ID = "..."
   $env:WCL_CLIENT_SECRET = "..."
   python tools\wcl_fetch.py --min-level 10 --max-level 16 --runs 25 --out "C:\...\AddOns\KeyChance\Data.lua"
   ```

   Полезные опции: `--region EU`, `--dungeon "Ara-Kara"` (можно несколько), `--zone <id>` (если сезон
   не определился сам). Повторные запуски берут уже скачанное из `tools/wcl_cache.json`.
   Бесплатный ключ API даёт ограниченное число очков в час — скрипт сам ждёт сброса лимита.
   Обновлять данные раз в неделю-две вполне достаточно.
4. В игре: `/reload`.

## Команды

| Команда | Действие |
|---|---|
| `/kc` | показать/скрыть окно |
| `/kc lock` | закрепить/открепить окно (перетаскивается мышью) |
| `/kc reset` | вернуть окно на место по умолчанию |
| `/kc bias 0.06` | насколько ваша группа обычно медленнее залогированных тайм-забегов (0.06 = 6%) |
| `/kc history` | сколько своих забегов сохранено |
| `/kc clearhistory` | очистить свою историю |

## Ограничения

- **Рейтинги WCL содержат только тайм-забеги**, к тому же залогированные группы обычно сильнее средних.
  Поэтому базовый шанс «до старта» опирается на параметр `bias`, а не на реальный процент таймов.
  Ваши собственные забеги (включая проваленные) записываются в историю и с вдвое большим весом уточняют
  модель — со временем прогноз подстраивается под ваш уровень игры.
- **Урон группы в 12.0 (Midnight)**: Blizzard ограничила доступ аддонов к боевому логу, а значения
  встроенного измерителя в бою могут быть «секретными». Аддон пробует по очереди встроенный измеритель
  урона, Details! и боевой лог, и обновляет урон вне боя. Если ни один источник не доступен, прогноз
  строится только по темпу убийства боссов — это основной сигнал, урон лишь уточняет ранний прогноз.
- Прогресс по % мобов в эталонных забегах WCL не хранится, поэтому между боссами модель опирается
  на время, а не на %.
- Если спек нового класса не распознаётся (например, Пожиратель охотника на демонов), проверьте его
  specID в [Specs.lua](KeyChance/Specs.lua).
- Если клиент пишет «устаревший аддон», обновите строку `## Interface` в
  [KeyChance.toc](KeyChance/KeyChance.toc) или включите «Загружать устаревшие модификации».
